Tema 2 · Nível B1

Used to

Hábitos e situações do passado

Velocidade do áudio
Used tocostumavaused to + base

1A forma

I used to play football. Eu costumava jogar.

Igual para todas as pessoas.

Pronúncia: “iús-tu”.

2Negativa e pergunta

I didn't use to like coffee.

Did you use to live here?

Com did, o used perde o d: use to.

3Hábito × situação

She used to smoke. hábito

There used to be a cinema here. situação

Hoje não é mais assim.

4Would (só hábitos)

Every summer, we would go to the beach.

Mais literário. Não serve para estados: I would live there

5Be used to = acostumado

I'm used to the cold. estou acostumado

I'm used to working at night. + -ing

Outro sentido! Leva be e -ing.

6Get used to = acostumar-se

I'm getting used to my new job.

You'll get used to it. Você vai se acostumar.

Erros comuns de brasileiros

I use to play.→I used to play.
Did you used to…?→Did you use to…?
I used to playing.→I used to play.
I'm used to work at night.→I'm used to working at night.
I'm used to play as a kid.→I used to play as a kid.

lightbulb Três parecidos, três sentidos

used to + basecostumava
be used to + -ingestar acostumado
get used to + -ingacostumar-se

Repare: depois de be/get, o verbo leva -ing.
