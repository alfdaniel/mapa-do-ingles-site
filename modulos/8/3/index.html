Tema 3 · Nível B1

Condicionais 0, 1 e 2

Se…, então…

Velocidade do áudio
If…se · entãoif + condição

1Zero: fatos

if + presentepresente

If you heat ice, it melts.

Sempre verdade. Aqui if = when.

2Primeiro: possível

if + presentewill + base

If it rains, I'll stay home.

Situação real no futuro.

3Segundo: hipótese

if + passadowould + base

If I had money, I'd travel.

Imaginário ou improvável agora.

4If I were you

If I were you, I'd accept. Se eu fosse você…

No 2º condicional: were para todos.

Perfeito para dar conselhos.

5Unless = a menos que

I'll go unless it rains.

= if it doesn't rain

Unless you study, you won't pass.

6A vírgula e a ordem

If I'm late, call me.

Call me if I'm late.

if no começo: vírgula. if no meio: sem vírgula.

Erros comuns de brasileiros

If it will rain, I'll stay.→If it rains, I'll stay.
If I would have money…→If I had money…
If I was you…→If I were you…
If I have time, I would go.→If I have time, I'll go.
Unless you don't study…→Unless you study…
