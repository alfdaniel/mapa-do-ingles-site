Tema 2 · Nível B2

Condicionais mistos

Passado que muda o presente

Velocidade do áudio
Condicionais
mistospassado ↔ presentehad done → would do

1Passado → presente

If I had studied medicine, I would be a doctor now.

Escolha passada, consequência hoje.

2Presente → passado

If I spoke English, I would have got that job.

Algo que é sempre verdade afetou o passado.

3Revisão rápida

0if + presente → presente
1ºif + presente → will
2ºif + passado → would
3ºif + had done → would have done

4Palavra-chave: now

If I'd saved money, I would be rich now.

now / today = a parte do presente.

5Vida real

If I hadn't met you, I wouldn't be so happy.

If she weren't so shy, she would have talked to him.

6Outros conectores

unlessa menos que
as long asdesde que
provided thatcontanto que
in casecaso, por precaução

Erros comuns de brasileiros

If I had studied, I would have been a doctor now.→…I would be a doctor now.
If I would speak English…→If I spoke English…
In case it will rain…→In case it rains…
Unless you don't hurry…→Unless you hurry…
If I were born in Italy…→If I had been born in Italy…

lightbulb in case ≠ if

Take an umbrella if it rains.só se chover
Take an umbrella in case it rains.por precaução

in case = para o caso de.
